# 中文运行说明

这是 ESE-D-26-01101R2 最终稿对应的独立项目，题目和五位作者已同步。
项目在本地整理，尚未向 GitHub 推送。按作者要求暂不指定开源许可证。

## 运行

使用 Python 3.10，安装 `requirements.txt` 后，在项目根目录运行：

```text
python scripts/validate_release.py
python reproduce.py
```

默认流程会重估 68 个回归规格，重新计算年度历史成本分解，从归档
CGE 均衡 CSV 重建经济结果，并据此生成五张图。结果在
`outputs/reproduction/`，不会覆盖源数据。只作图可以运行
`python reproduce.py --stage figures`。

复现图件为 SVG/PDF/PNG/TIFF；无需 PowerPoint。投稿版使用 Arial，
其他机器缺少此字体时可能发生字体替换。`figures/submitted/` 保存已核对
的投稿 SVG 和预览 PNG。

## 复现边界

- 历史成本分解使用 10 个光伏市场、13 个风电市场，2010–2024 年。
- 25.5% 和 26.8% 是贡献占观察到的成本下降的比例。
- 代码旧字段 `G_other` 对应最终稿 E，不是新增机制。
- 默认流程的 CGE 部分是归档均衡结果后处理，不是重新求解模型。
- 完整求解所需 Julia 代码另放在 `cge/`，需要合法取得的基准数据和
  PATH 许可；这些数据、许可字符串不进入公开包。
- 默认流程未声称复现所有 SI 备选模型搜索、单位根及其他诊断表。
