The research code and derived analysis tables are distributed as the authors' replication materials. Existing copyright and attribution notices in the GRID/GHEER source modules are preserved, including the notices naming Kangxin An and Can Wang, School of Environment, Tsinghua University.

This packaging step does not assign a new blanket MIT, BSD or other open-source license. No such repository license was found in the previous repository. Any applicable original permissions and third-party data terms remain in force. The benchmark files are the project's prepared aggregates, not a redistribution of the complete underlying commercial database.

Third-party reports, libraries and solver binaries are not bundled. The Julia/Python dependency specifications identify separately installed software. No PATH license key, account credential, private Git metadata or local Python environment is included. Users who re-solve the large CGE model must supply their own PATH license.

Geographic plotting assets are retained from the project repository. Their original provenance should accompany any downstream redistribution; this package does not assert a new license over those assets.
